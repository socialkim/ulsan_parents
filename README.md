**울산 AI디지털배움터 · 『AI 시대, 부모로 살아가기』 김덕진 강연 실습 페이지** (2026.10.24, 청소년차오름센터)

실습 페이지 주소(배포 후): https://socialkim.github.io/ulsan_parents/

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| 준비 | 앱 하나 열기, 마이크 찾기, 혼자/아이와 함께 안내, 넣지 않는 다섯 가지 |
| 실습 1 · 질문하는 AI | 같은 문제를 '그냥 묻기'와 '힌트만 달라기'로 비교, 과목 바꿔 보기, 공부 모드 위치 |
| 실습 2 · 말로 그리기 | 특징 세 가지 → 말하기 → 살펴보고 다시 말하기 → (선택) 대화창 미니 게임 |
| 고치는 말 | 더하기·빼기·바꾸기·크기·지키기·정확히 하기·되돌리기 + 부모의 질문 네 가지 |
| 안전 설정 | 학습 끄기, 임시 채팅, 반대 근거 습관, 가족 암호, 부모 연결 기능 |
| 우리 집 약속 | 5원칙 + 우리 집 한 줄 쓰기(이 휴대폰에만 저장) |
| 집에서 더 | 동화 잇기, 역사 인물 대화, 하브루타, AI 틀리게 만들기, 수찬이 기록, 자주 묻는 질문 |

## 배포

GitHub 저장소 `socialkim/ulsan_parents`에 index.html을 올리고 Settings → Pages → Branch `main` / `(root)` → Save.
주소가 바뀌면 강의 덱 7장·마지막 장의 QR을 다시 만들어야 합니다.
